# RunnyGuy · 抓捕狗狗

一款竖屏微信小游戏：玩家画出限时能量障碍，利用物理反射把逃跑的狗狗引入安心圈。

## 代码位置

这不是只有策划文档的仓库。可运行代码位于：

- `game.js`：微信小游戏入口。
- `src/game.js`：游戏循环、触控、关卡、判定和 Canvas 渲染。
- `src/physics.js`：线段碰撞与反射计算。
- `src/config.js`：犬种及六个 MVP 关卡配置。
- `src/progression.js`：星级、解锁和微信本地存档。
- `test/core.test.js`：核心逻辑自动化测试。

## 在微信开发者工具运行

1. 克隆或下载完整仓库，而不是只下载 `docs` 目录。
2. 使用微信开发者工具导入仓库根目录，项目类型选择“小游戏”。
3. 使用测试 AppID，或将 `project.config.json` 中的 AppID 换成自己的小游戏 AppID。
4. 编译后点击“开始巡逻”，在场地内拖动画出反射障碍。

当前 MVP 包含两个犬种、每个犬种 1/2/3 犬关卡、画线能量、限时障碍、物理反射、随机转头预警、安心圈捕捉、星级和本地进度存档。
